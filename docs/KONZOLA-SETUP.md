# 🛠️ МОНЕТА Конзола — Поставување (еднаш, ~10 мин)

Конзолата е скриена админ страна на `https://vloski.mk/konzola.html` со која
клиентот управува со **производи, попусти/кампањи и залихи** — без да го допира Supabase.
Заштитена е со лозинка, а запишувањето оди преку Edge Function (`admin-api`)
со `service_role` клуч (безбедно, клучот не се гледа никаде во кодот на страната).

---

## Чекор 1 — SQL (еднаш): додај ги колоните за кампањи

Supabase → **SQL Editor** → **New query** → залепи и **Run**:

```sql
ALTER TABLE products ADD COLUMN IF NOT EXISTS discount_from timestamptz;
ALTER TABLE products ADD COLUMN IF NOT EXISTS discount_until timestamptz;
```

## Чекор 2 — Креирај ја Edge Function-ата

1. Supabase → лево мени → **Edge Functions**
2. **Create a new function** → име: **`admin-api`**
3. Избриши го примерокот и **залепи го целиот код** од:
   `supabase/functions/admin-api/index.ts`
4. **Deploy**

## Чекор 3 — Тајни (secrets)

Supabase → **Edge Functions** → кликни на `admin-api` → **Settings / Secrets** → додади 2:

| Име | Вредност |
|---|---|
| `ADMIN_PASSWORD` | лозинка што ќе ја користи клиентот (изберете силна) |
| `SUPABASE_SERVICE_ROLE_KEY` | од **Settings → API → service_role → Reveal** (долгиот клуч `eyJhbGci...`) |

Зачувај ги тајните. (После промена на тајни — повторно **Deploy** на функцијата.)

## Чекор 4 — Тест

1. Отвори `https://vloski.mk/konzola.html`
2. Внеси ја лозинката од `ADMIN_PASSWORD` → **Најава**

Ако работи → му ја даваш адресата и лозинката на клиентот. Готово. 🎉

---

## Што може клиентот во Конзолата

- 📦 **Производи**: мрежа/табела како сајтот — слика, цена, попуст, залиха, статус
- ➕ Додади нов / ✏️ Измени / 🗑 Избриши производ
- 📅 **Кампањи**: за секој производ — % попуст + „од датум/време“ до „до датум/време“
  (календар-бирачи; празно „Од“ = веднаш, празно „До“ = без крај; кога ќе помине — сам престанува)
- 🔢 **Залиха**: количини по големини, додавање/бришење големини (qty 0 = сив производ)

> 📌 Напомена: конзолата е скриена од Google (`noindex`), но адресата е позната —
> заштитата е лозинката. Користете силна лозинка и не споделувајте ја јавно.
